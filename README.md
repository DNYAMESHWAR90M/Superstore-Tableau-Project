# 📊 E-Commerce & Retail Sales Data Analytics

## 📌 Project Overview

This project presents an interactive Tableau dashboard built using the Superstore Sales dataset. The dashboard provides insights into sales performance, profitability, customer behavior, product performance, and payment methods.

---

## 🎯 Project Objectives

- Analyze sales performance
- Track profit trends
- Identify top-performing products
- Analyze customer ratings
- Compare revenue across countries
- Understand payment method distribution

---

## 📊 Dashboard Features

✅ KPI Cards

- Total Customers
- Average Order Value
- Total Products Sold
- Average Customer Rating
- Profit Margin

---

### Visualizations

- Revenue vs Profit Trend
- Top 10 Products by Revenue
- Top 10 Customers by Revenue
- Customer Rating vs Profit
- Sales by Country
- Profit Contribution by Category
- Payment Method Donut Chart
